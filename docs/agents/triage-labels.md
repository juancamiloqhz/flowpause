# Triage Labels

The skills use five canonical workflow roles. This file maps those roles to the
actual GitHub labels used by FlowPause.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous agent work |
| `ready-for-human` | `ready-for-human` | Requires human judgment or action |
| `wontfix` | `wontfix` | Intentionally declined |

Classification labels such as `bug`, `enhancement`, `documentation`, and
`accessibility` remain independent of these workflow-state labels.
